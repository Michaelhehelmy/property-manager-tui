Local-first Property Manager — Terminal (TUI) + Web

Cross-platform via terminal and browser: run the TUI locally or serve the Web UI and access it from any device on your network (or via SSH/VPN). One command per OS installs on first run, or checks for updates and launches on re-run — then you choose TUI or Web in the launcher. Runtime data (DB/exports/invoices) is preserved.

Recommended for your device

Install / update / launch

Windows 10/11

PowerShell (one-liner)

Works on Windows PowerShell 5.1 and PowerShell 7+. Bootstraps Python/Git via winget if needed, installs/updates, and runs setup.

irm https://raw.githubusercontent.com/Michaelhehelmy/property-manager-tui/main/scripts/install_windows.ps1 | iex

If you already have the repo: powershell -ExecutionPolicy Bypass -File .\scripts\setup_windows.ps1 -Action deploy -Mode auto. Web (local): set $env:MODE='web'; $env:HOST='127.0.0.1'; $env:PORT='8000'; $env:PM_WEB_SECRET_KEY='<strong-random>' before running.

Linux / macOS / WSL

curl or wget (install / update / launch)

curl -fsSL https://raw.githubusercontent.com/Michaelhehelmy/property-manager-tui/main/scripts/install.sh | sh
wget -qO- https://raw.githubusercontent.com/Michaelhehelmy/property-manager-tui/main/scripts/install.sh | sh

Same command on re-run updates & launches. TUI-only: | SKIP_WEB=1 MODE=tui sh. Web: | MODE=web HOST=127.0.0.1 PORT=8000 PM_WEB_SECRET_KEY="$(openssl rand -hex 32)" sh.

Android (Termux)

Terminal + Web

pkg update -y && pkg install -y curl
curl -fsSL https://raw.githubusercontent.com/Michaelhehelmy/property-manager-tui/main/scripts/install.sh | sh

Installs/updates and launches the launcher (choose TUI or Web). If web deps fail to build (e.g. pydantic-core/maturin/Rust wheel issues), use TUI-only: | SKIP_WEB=1 MODE=tui sh.

iOS (iSH / SSH)

TUI recommended (iSH Alpine)

apk add --no-cache curl
curl -fsSL https://raw.githubusercontent.com/Michaelhehelmy/property-manager-tui/main/scripts/install.sh | SKIP_WEB=1 MODE=tui sh

For iPhone/iPad without iSH: SSH into a server running the TUI, or open the Web UI via LAN/VPN (HOST=0.0.0.0, --workers 1, strong PM_WEB_SECRET_KEY, HTTPS for remote/shared access).

After install (and on every re-run)

  • Same command = auto: first run installs everything; re-run checks for updates (git fast-forward), refreshes deps, and launches the launcher (choose TUI or Web).
  • Run manually: cd ~/property-manager-tui && . .venv/bin/activate && python3 launcher.py (or --tui / --web).
  • Web on LAN/phones: bind 0.0.0.0, set a strong PM_WEB_SECRET_KEY, and run with a single worker (--workers 1, SQLite). For shared/remote access use HTTPS (reverse proxy/VPN/private network), not plain public HTTP.
  • Phones via SSH: connect to the host and run the TUI — no native mobile app required.
  • Updates & data: in-app Settings → App updates (fast-forward, restart) or re-run the install command; runtime data (DB/exports/invoices/PM_DATA_DIR) is preserved.
  • Troubleshooting (Termux/constrained): if web dependency builds fail (e.g. pydantic-core/maturin), rerun with SKIP_WEB=1 MODE=tui. On Windows, scripts are compatible with PowerShell 5.1+ (if issues persist in an existing checkout, run git pull --ff-only and use .\scripts\setup_windows.ps1).
Security: one-line installers download and execute scripts — review them and prefer HTTPS. For non-local/shared web access use HTTPS (reverse proxy/VPN), strong secrets, and keep --workers 1.
