    Recommended install / update / launch

    Install / update / launch

    Windows 10/11

    Native build or PowerShell installer

    If a native Windows build is published in Releases, download and run it. Otherwise use the one-liner installer (PowerShell 5.1+/7+, bootstraps Python/Git via winget when needed). Re-run to update.

    irm https://raw.githubusercontent.com/Michaelhehelmy/spms/main/scripts/install_windows.ps1 | iex

    Recovery: $env:REPAIR='1'; irm ... | iex. Web (local): set $env:MODE='web'; $env:HOST='127.0.0.1'; $env:PORT='8000'; $env:PM_WEB_SECRET_KEY='<strong-random>'.

    Linux / macOS / WSL

    Native build or script installer

    curl -fsSL https://raw.githubusercontent.com/Michaelhehelmy/spms/main/scripts/install.sh | sh
    wget -qO- https://raw.githubusercontent.com/Michaelhehelmy/spms/main/scripts/install.sh | sh

    Re-run to update. Recovery: REPAIR=1. Web (local): | MODE=web HOST=127.0.0.1 PORT=8000 PM_WEB_SECRET_KEY="$(openssl rand -hex 32)" sh.

    Android (Termux)

    Script install (Termux)

    pkg update -y && pkg install -y curl
curl -fsSL https://raw.githubusercontent.com/Michaelhehelmy/spms/main/scripts/install.sh | sh

    Native Android APK packaging is separate from desktop release builds. If web dependencies fail to build, install required build deps/toolchain or run the Web UI on a supported host. Recovery: REPAIR=1.

    iOS (iSH / SSH / Web)

    Run on a host and access in browser

    apk add --no-cache curl
curl -fsSL https://raw.githubusercontent.com/Michaelhehelmy/spms/main/scripts/install.sh | MODE=web sh

    No native iOS app package is provided; run the Web UI on iSH or another host, then open it over LAN/VPN/HTTPS (or via SSH port forwarding).

    After install / download

    • Native builds: download the asset for your OS/arch from the latest GitHub Release (Windows: .exe, Linux: single binary and/or .AppImage, macOS: .dmg), verify checksum if provided, then run/install. On Linux you may need chmod +x. Runtime data (DB/exports/invoices/PM_DATA_DIR) is preserved outside the bundle; follow release notes for update/replace steps.
    • Script installs: re-run the same command to update (git fast-forward + deps refresh) and launch. Recovery for stuck git state: REPAIR=1 (Unix/Termux) or $env:REPAIR='1' (Windows).
    • Run manually: cd ~/spms && . .venv/bin/activate && python3 launcher.py --web (or python3 -m uvicorn ui.web.server:app --host 127.0.0.1 --port 8000 --workers 1).
    • Web on LAN/phones: bind 0.0.0.0, set strong PM_WEB_SECRET_KEY, run with --workers 1 (SQLite). Use HTTPS (reverse proxy/VPN/private network) for shared/remote access.
    • Updates & data: in-app Settings → App updates (git installs), or re-run installer, or download newer native release; runtime data (DB/exports/invoices/PM_DATA_DIR) is preserved.
    Security: review installers/scripts and binaries before running. Prefer HTTPS and official GitHub Releases. Native builds are published per release when available; if no matching asset exists for your platform, use the script installer above.

    Send an issue report from the app

    If you hit a problem, generate a report inside the app (Report issue) and download the JSON report (it includes sanitized diagnostics, device/OS info, recent steps, and your description). You can upload that file here to send it to the maintainer, or open a GitHub issue manually and attach it.

    Open GitHub issue manually

    Privacy: review the report before uploading. It should not contain passwords, secrets, tokens, session/recovery codes, or database/guest/payment records. Upload delivery depends on site configuration (Cloudflare Pages Function + GitHub token); if unavailable, download/attach the report to a GitHub issue manually.
