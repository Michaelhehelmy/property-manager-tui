    Recommended install / update / launch

    Install / update / launch

    Windows 10/11

    Native build or PowerShell installer

    If a native Windows build is published in Releases, download and run it. Otherwise use the one-liner installer (PowerShell 5.1+/7+, bootstraps Python/Git via winget when needed). Re-run to update.

    irm https://raw.githubusercontent.com/Michaelhehelmy/property-manager-tui/main/scripts/install_windows.ps1 | iex

    Recovery: $env:REPAIR='1'; irm ... | iex. Web (local): set $env:MODE='web'; $env:HOST='127.0.0.1'; $env:PORT='8000'; $env:PM_WEB_SECRET_KEY='<strong-random>'.

    Linux / macOS / WSL

    Native build or script installer

    curl -fsSL https://raw.githubusercontent.com/Michaelhehelmy/property-manager-tui/main/scripts/install.sh | sh
    wget -qO- https://raw.githubusercontent.com/Michaelhehelmy/property-manager-tui/main/scripts/install.sh | sh

    Re-run to update. Recovery: REPAIR=1. TUI-only: | SKIP_WEB=1 MODE=tui sh. Web: | MODE=web HOST=127.0.0.1 PORT=8000 PM_WEB_SECRET_KEY="$(openssl rand -hex 32)" sh.

    Android (Termux)

    Terminal + Web (script install)

    pkg update -y && pkg install -y curl
curl -fsSL https://raw.githubusercontent.com/Michaelhehelmy/property-manager-tui/main/scripts/install.sh | sh

    Native Android APK packaging is separate from desktop Nuitka builds. If web deps fail to build, use SKIP_WEB=1 MODE=tui. Recovery: REPAIR=1.

    iOS (iSH / SSH / Web)

    TUI or remote Web UI

    apk add --no-cache curl
curl -fsSL https://raw.githubusercontent.com/Michaelhehelmy/property-manager-tui/main/scripts/install.sh | SKIP_WEB=1 MODE=tui sh

    No native iOS app package from Nuitka; use iSH (TUI), SSH to a host, or open the Web UI over LAN/VPN/HTTPS.

    After install / download

    • Native builds: download the asset for your OS/arch from the latest GitHub Release, verify/checksum if provided, then run/install. Native bundles still preserve runtime data in configured data dirs; follow release notes for update/replace steps.
    • Script installs: re-run the same command to update (git fast-forward + deps refresh) and launch. Recovery for stuck git state: REPAIR=1 (Unix/Termux) or $env:REPAIR='1' (Windows).
    • Run manually: cd ~/property-manager-tui && . .venv/bin/activate && python3 launcher.py (or --tui / --web).
    • Web on LAN/phones: bind 0.0.0.0, set strong PM_WEB_SECRET_KEY, run with --workers 1 (SQLite). Use HTTPS (reverse proxy/VPN/private network) for shared/remote access.
    • Updates & data: in-app Settings → App updates (git installs), or re-run installer, or download newer native release; runtime data (DB/exports/invoices/PM_DATA_DIR) is preserved.
    Security: review installers/scripts and binaries before running. Prefer HTTPS and official GitHub Releases. Native builds (e.g. Nuitka) are published per release when available; if no matching asset exists for your platform, use the script installer above.
