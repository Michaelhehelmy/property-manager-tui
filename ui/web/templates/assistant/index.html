English chat grounded in real backend data (read-only). Ask in plain language — I’ll route to the right tools and answer with facts. Replies are polished locally (no external LLM).

How to use the Manager Assistant
  • Ask naturally: include what you want and context (guest/reservation ID, report name, date range like last month or 2026-11-01 to 2026-11-30).
  • Guests: find guest Sara, show guest #3 full portfolio (all stays, POS/orders, payments, invoices), what did guest #3 order most on last visit?, guest #3 last visit spend, what activities did guest #3 book?
  • Business/ops/money: business partner briefing for this month, today's ops, who owes money?, P&L last month, compare this month vs last month, occupancy last month, any low stock items?, top selling items this month
  • Reservations & catalog: reservation #12 summary, reservation #12 balance, list registered activities, activity booking statistics, ledger integrity check
  • Clarifications: if multiple guests match or details are missing, I’ll ask you to specify (reply with the suggested ID).
  • Feedback: use 👍/👎 or correct the intent so I learn your phrasing over time. I only read real app data (no changes, no guesses).
