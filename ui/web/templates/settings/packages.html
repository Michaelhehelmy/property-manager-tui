Packages & Bundles

Foundation for bundled offerings (packages of services/add-ons). Applying a package to a reservation posts its items to the folio with ledger/tax handling and stores an application snapshot.

Create package

Notes

  • Package items can reference the service catalog or be custom descriptions/prices.
  • Applying a package creates posted service/folio lines (and ledger entries) per item; voiding the applied package reverses those lines.
  • Use reservation detail to apply packages; manage definitions here.
