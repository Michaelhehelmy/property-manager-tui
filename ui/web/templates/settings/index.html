Settings / Branding

Configure property, branding, master data, and maintenance. Protected actions require unlock/super password.

How to use Settings
  • Branding & general: update property name/tagline and app settings (some changes may require unlock).
  • Seed config (first-time / master data): Export current config to JSON, edit, then Import/Apply (requires unlock + super password + confirmation, and is only allowed when no operational data exists) — use this to seed rooms, rate plans, inventory (incl. SKU/barcodes & batch/expiry fields), expense categories, meals, and activities.
  • Demo data presets: load synthetic operational/business demo data (reservations, POS, booked activities, payments, expenses) on a DB with no operational data to explore the app quickly.
  • Rooms: add/remove rooms (removal blocked if referenced by reservations).
  • Rate plans / backups / health: manage pricing plans, backups, and run health/integrity checks.
