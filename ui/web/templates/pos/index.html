POS / Inventory

Reservation POS posts items immediately to the folio (real backend). Walk-in uses a multi-item cart committed atomically via complete_walkin_sale with a linked receipt.

How to use POS / Inventory / Activities / Barcodes & Batches
  • Barcode/scan: use the Scan/Lookup box (keyboard-wedge scanners work as typed input + Enter) to resolve an item or lot/batch barcode and see data (received/bought time, expiry, remaining). You can add the resolved item/batch to cart or reservation POS.
  • Reservation charges: select a reservation, enter item/qty/price (and optional inventory/batch) to post directly to its folio/invoice.
  • Walk-in sale: add items to the cart, then “Complete walk-in sale” to commit atomically with a receipt.
  • Inventory & batches: add items with SKU/barcode, Receive batch/lot to record time bought/received, expiry, cost/supplier and generate a lot barcode; restock also records a batch. Batch-tracked sales deduct by FEFO and record the lot on the sale.
  • Labels: print item or batch labels (sent to configured label/default printer or saved file). Batch labels include lot, received, expiry and an embedded data payload.
  • Meals & activities: recipe meals auto-deduct ingredients (batch-aware); activities book to reservation folio/invoice.
