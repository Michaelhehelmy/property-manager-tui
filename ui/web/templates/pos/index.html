How to use Sell / Scan
  • Barcode/scan: keyboard-wedge scanners work as typed input + Enter. Resolves item SKU/barcode or lot/batch and shows received/bought time, expiry, remaining.

  • Walk-in sale: add items to cart, then “Complete walk-in sale” to commit atomically with a linked receipt.
  • Use Inventory, Batches, Meals, and Activities tabs for setup and traceability details.

How to use Batches & Traceability
  • Receive batch/lot: records received/bought time, expiry, cost/supplier, updates stock, and can print a batch label with data payload.

  • Labels: print item or batch labels (configured printer or saved file).
